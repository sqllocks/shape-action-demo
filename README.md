# shape-action-demo

A demo of the [Shape](https://github.com/sqllocks/shape) GitHub Action gating pull requests on data drift.

- `data/orders.csv` — 5,000 synthetic orders generated by Shape 0.9.1 (`shape generate retail --scale small --seed 42`). No real data.
- `baseline/orders.shape` — the baseline profile of that file (`shape profile data/orders.csv --name orders`).
- `shape.yml` — the Shape project: one source, `orders`, compared with its pinned baseline.
- `.github/workflows/shape.yml` — on every pull request, profiles `orders`, compares it with the baseline, posts the result as a comment and fails the check on drift (`fail-on: drift`).

Change `data/orders.csv` in a pull request and the check reports what moved.
